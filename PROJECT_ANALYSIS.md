## Ключевая бизнес-логика
1. **Вопрос** = заголовок + описание + синтезатор (или «не знаю») + аудио (≤60 c демо-пример, трим ≤7 c, захват с компа ≤27 c) + маркеры. Тип звука/сложность/теги определяет ОТВЕЧАЮЩИЙ.
2. **Жизненный цикл решения:** «✓ Решение» → +25 rep автору ответа (разово), вопрос живёт 7 дней (отсчёт на странице, напоминания автору 24 ч / 3 дня), затем purge → заглушка «вопрос решён, лучший ответ — @user» (рейтинги/статистика навсегда). Отмена решения — таймер снят, rep остаётся.
3. **Синтезатор «Другой»** → «+» добавляет вариант в общий `synth_catalog` (виден всем). DAW — так же в `daw_catalog`.
4. **Аудио:** вейвформа строго по реальным пикам (пики извлекаются ДО сжатия); A/B-плеер (вопрос vs ответ): клик по стороне = play/pause, старт всегда с начала (редизайн 2026-10-11); все ▶ маркеров стартуют с начала маркера; пины+чипы маркеров — во ВСЕХ списках карточек (лента, /favorites, вкладки профиля «Вопросы»/«Избранное», витрина «Лучшие ответы» — паритет 2026-10-11); нормализация громкости; загрузка — webm/opus 48 kbps mono (Safari — mp4/AAC, фолбэк WAV) с EBML-патчем Duration (fixWebmDuration) для мгновенных seek.
5. **Демо/реал:** все функции слоя данных имеют две ветки (isDemo()); демо персистится локально.

## Конвенции кода
- Всё на ES Modules `.mjs` в `public/js/`, импорты только относительные `./x.mjs` (проверяет check-imports).
- Рендер экранов: `renderXxx(container, params) => cleanup?` (cleanup — таймеры/плееры/подписки; роутер вызывает при уходе + cleanupTransientAudio).
- Текст только через `t('key')` / `tp()` (плюрализация); ключи обязаны быть в ru — единственной активной локали (check_keys.cjs; ru-only заморозка 2026-10-11).
- Новый интерактивный элемент ⇒ `data-help="ключ"` + `help.items.<ключ>.title/desc` в ru (check_help_catalog.cjs) — иначе контекстная справка «протухает».
- HTML — через шаблонные строки с экранированием (utils.escapeHtml / format.mjs); никакой innerHTML из сырого пользовательского ввода.
- Браузерные подсказки в полях запрещены (2026-10-13): новые form/input/textarea НЕ требуют ручных атрибутов — `initNoBrowserHints()` (boot) проставляет autocomplete=off/novalidate сам, включая поздно созданные поля; статический скан в test_no_browser_hints.mjs не даст шаблону вернуться к autocomplete!="off" или форме без novalidate.
- Дизайн: тёмная тема, медные акценты, CSS-переменные в style.css.
- Тесты — в tmp_tests/, запуск `node tmp_tests/test_*.mjs` из корня; DOM-тесты на jsdom (ставится --no-save).
- Комменты и документация — на русском.
