# Архив локалей (заморозка ru-only от 2026-10-11)

Проект заморожен на русском языке: аудитория и вся инфраструктура
русскоязычные (РСЯ, Метрика, Selectel, донаты в ₽), а иностранным гостям
достаточно встроенного браузерного перевода страницы (Chrome/Safari/
Яндекс.Браузер сами предлагают перевод для `<html lang="ru">`).

Здесь лежат полные словари **EN (649 ключей)** и **DE (649 ключей)** в том
виде, в котором они были на момент заморозки.

## Почему не удалили слой i18n

`public/js/i18n.mjs` (`t()`, `tp()`, `setLocale()`, `data-i18n`) остался
в коде целиком — все модули по-прежнему ходят за строками через `t()`.
Стоимость поддержки была не в механике, а в переводе каждой новой строки ×3.

## Как вернуть язык (часы работы, не дни)

1. Скопировать нужный JSON отсюда в `public/locales/`.
2. **Досинхронизировать**: словарь устарел — добавить все ключи, появившиеся
   после заморозки (свериться с `public/locales/ru.json`; поможет
   `tmp_tests/check_keys.cjs`, если временно вернуть язык в список локалей).
3. Добавить код языка в `CONFIG.LOCALES` (`public/js/config.mjs`).
4. Вернуть переключатель языка в «Настройки профиля» (`profile.mjs`,
   стили `.lang-switcher` в `style.css` не удалялись).
5. Вернуть `og:locale:alternate` в `public/index.html`.
6. Вернуть проверки локалей в `tmp_tests/check_keys.cjs` и
   `tmp_tests/check_help_catalog.cjs` (список `['ru']` → `['ru', 'en']`).

## Триггер пересмотра

Устойчивые >5–10% не-RU трафика по отчёту «География» в Яндекс.Метрике.
