# 🎛️ SampleHelp

Q&A-платформа для саунд-дизайнеров и синтезаторщиков. Загрузи аудио-пример звука — сообщество подскажет, как воссоздать его в Serum, Phase Plant, Vital и др.

**Стек:** чистый HTML5 + CSS3 + ванильный JavaScript (ES Modules, `.mjs`). Без фреймворков и сборщиков. Бэкенд: Node.js + Express (статика), данные/аутентификация/хранилище/Realtime — Supabase.

## 🚀 Быстрый старт

```bash
npm install
npm start          # → http://localhost:3000
npm run dev        # с автоперезапуском (nodemon)
```

> **Демо-режим:** если ключи Supabase не заданы, приложение работает
> с моковыми данными и **процедурно генерируемым аудио** (басы, пэды, FX
> синтезируются в WAV прямо в браузере). Вейвформы строятся по **реальным пикам**
> сгенерированных семплов — форма волны всегда соответствует звуку.

## 🔌 Подключение Supabase

1. Создайте проект на [supabase.com](https://supabase.com).
2. Выполните `supabase/schema.sql` в SQL Editor (таблицы + RLS + Realtime + справочники DAW/синтезаторов).
3. Создайте бакеты Storage: `question-audio`, `presets`, `avatars` (публичные), `marketplace-files` (приватный).
4. Включите OAuth-провайдеров (Google / GitHub / Apple) в Authentication → Providers.
5. Впишите ключи в `public/js/config.mjs`:

```js
SUPABASE_URL: 'https://xxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJhbGci...',
```

## ✨ Ключевые особенности

- **Лента**: клик по карточке раскрывает **ответы и комментарии прямо под карточкой**; клик по аватару/имени открывает профиль; заголовок ведёт на страницу вопроса.
- **Вопрос**: только заголовок, описание, синтезатор (если известен) и аудио — тип звука, сложность и теги **определяет отвечающий** в форме ответа.
- **Синтезатор «Другой»**: кнопка «+» добавляет свой вариант в **общий справочник** (`synth_catalog`) — он становится доступен всем.
- **Аудио**: вейвформа строго по реальным пикам семпла, обрезка регионами (WaveSurfer.js + офлайн-фолбэк), нормализация громкости через OfflineAudioContext. Спектрограмма и зацикливание не реализуются.
- **Профиль**: смена аватара (загрузка файла), ссылки добавляются кнопкой «+» — **платформа распознаётся автоматически** по URL и отображается с inline-SVG логотипом (Instagram, YouTube, SoundCloud, Spotify, Bandcamp, X, Telegram, TikTok…); DAW выбираются в модалке из справочника (`daw_catalog`), свой вариант — через «+». Навыки — теги-чипсы.
- **Настройки профиля**: модалка «⚙ Настройки профиля» с **автосохранением** — кнопки «Сохранить» нет: текстовые поля (имя, био) сохраняются с debounce, переключатели и пикеры (обложка, коллаборации, DAW, арсенал, ссылки, навыки) — мгновенно; незавершённые изменения досохраняются при закрытии. Внизу — строка статуса («Сохранение…» → «Сохранено ✓») и кнопка «Готово». **Переключатель языка переехал сюда из шапки**: применяется сразу и переводит саму модалку на глазах. Пустое имя не сохраняется; во время ввода поле не подменяется — откат к сохранённому имени только при потере фокуса.
- **Обложка профиля**: вейвформа детерминированно генерируется из `userId` (inline-SVG, у каждого своя волна) и рисуется одним из **пяти стилей на выбор пользователя** — Глубина, Зеркало, Спектр, Волна, Студия (`js/covers.mjs`, сохраняется в `profiles.cover_style`). Выбор — в «Настройках профиля»: превью каждого стиля живое, обложка меняется на глазах, выбранный стиль **сразу автосохраняется**.
- **Форматирование текста**: в вопросах, ответах и комментариях — `**жирный**`, `*курсив*`, `` `код` ``, блоки кода ```…```, `> цитаты`, `- списки`, автоссылки. Над полями ввода — мини-тулбар. Разметка своя (`js/format.mjs`): текст сначала полностью экранируется, поэтому вставить произвольный HTML/XSS нельзя. В превью ленты и профиля маркеры снимаются.
- **Правка и удаление своего**: вопрос (✏️/🗑 в ленте и на странице вопроса, правка — на `/ask?edit=<id>`), ответ (инлайн-форма внутри карточки), комментарий (инлайн). После изменения появляется метка «(изменено)». Удаление ответа-решения возвращает вопросу статус «открыт», счётчики обновляются на месте.
- **Навигация**: иконки (лента, избранное, сообщения, уведомления) с tooltip и aria-label.
- **Realtime**: мгновенные сообщения и уведомления.
- **Достижения**: 🚀 Первый ответ, 💬 Собеседник, 🔥 В огне, ✅ Решатель, 🎯 Эксперт тега (по тегам ответов), 🎧 Меломан, 🤝 Помощник, 👑 Легенда, 📎 Щедрый, ⭐ Куратор.
- **i18n**: RU / EN / DE, переключение языка — в «Настройках профиля» (в шапке переключателя больше нет).

## 💰 Монетизация (заложена, выключена)

Модули `marketplace.mjs`, `premium.mjs`, `affiliate.mjs` и таблицы `products`, `orders`, `subscriptions_premium`, `affiliate_links` — заготовки. Активация: `ENABLE_MONETIZATION: true` в `config.mjs`. Платёжная система не интегрируется — экраны показывают заглушку «Скоро».

## 🚫 Осознанно НЕ реализовано (по ТЗ)

- Спектрограмма (убрана — только вейвформа)
- Таймкод-ссылки (убраны)
- Челленджи и база знаний (удалены)
- Автоперевод контента (отложен)
- Полнотекстовый поиск и сложная фильтрация
- Зацикливание области воспроизведения
- Мини-синтезатор
- JSX/фреймворки/сборщики — только чистый стек
